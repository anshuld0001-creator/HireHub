# HireHub 🚀

HireHub is a Django-based recruitment platform designed to simplify the hiring process by connecting job seekers and employers in one place.

## 📌 About the Project

HireHub provides a centralized platform where users can explore job opportunities, manage profiles, and streamline recruitment activities through a simple and user-friendly interface.

The project demonstrates practical implementation of web development, database management, authentication, and recruitment workflows using Django.

## ✨ Features

- 👤 User registration and authentication
- 🔐 Secure login and logout
- 💼 Job opportunity management
- 🔎 Browse and explore available jobs
- 👨‍💼 Employer and job-seeker profiles
- 📝 Job application management
- 🖼️ Profile picture support
- 📊 Database-driven application
- 📱 Clean and responsive user interface

## 🛠️ Technologies Used

- **Django**
- **SQLite**

⚙️ Installation & Setup
1. Clone the repository
git clone https://github.com/YOUR-USERNAME/hirehub.git
cd hirehub
2. Create a virtual environment
python -m venv venv
3. Activate the virtual environment

Windows:

venv\Scripts\activate

Linux/macOS:

source venv/bin/activate
4. Install dependencies
pip install -r requirements.txt
5. Run database migrations
python manage.py migrate
6. Start the development server
python manage.py runserver

Open your browser and visit:

http://127.0.0.1:8000/
🔑 Admin Panel

To create a Django admin account:

python manage.py createsuperuser

Then visit:

http://127.0.0.1:8000/admin/
